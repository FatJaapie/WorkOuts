Google Sheet backup

The link and password stay in this browser only. Restore adds any workouts from the Sheet that this page is missing.

Set up the Sheet (one time)
  1. Open sheets.new in Chrome to make a blank Google Sheet. Name it Lift Log backup.
  2. Choose Extensions, then Apps Script. On a phone, switch Chrome to Desktop site first.
  3. Delete the code that is there. Tap Copy script below and paste it in. Change change-this-password on the first line to a password of your own.
  4. Tap Deploy, then New deployment. For type pick Web app. Set Execute as to Me and Who has access to Anyone. Tap Deploy.
  5. Google asks for permission. Tap Advanced, then Go to the project, then Allow. This is your own script.
  6. Copy the Web app URL it shows (it ends in /exec). Paste it above with the same password, tap Save settings, then Back up now.
